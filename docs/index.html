How MMC runs jobs

One VM per job
MMC starts an Apple container VM when a job needs one and removes it after the job.
Runs after login
The runner operates in your macOS user session. After a restart, jobs can resume once you log in.
Shared job network
MMC checks network isolation before starting runners. Concurrent jobs share a network and can reach one another.
